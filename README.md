# Upswing site

Support and privacy pages for the Upswing iPhone app, served at
https://dragoscacuci.github.io/upswing-site/

- `index.html`: support and FAQ (the App Store "Support URL")
- `privacy.html`: privacy policy (the App Store "Privacy Policy URL")
- `style.css`, `icon.png`: shared styling and the app icon

The app's source code lives in a separate private repository.
